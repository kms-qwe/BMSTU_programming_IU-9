## 1. Описание входного языка

Входной язык предназначен для задания контекстно-свободных грамматик.

Каждое правило имеет вид:

<нетерминал> \`is <альтернатива> { \`or <альтернатива> } \`end

Также может присутствовать объявление аксиомы:

\`axiom <нетерминал> \`is ... \`end

Альтернатива может содержать:
- последовательность символов (терминалов и нетерминалов)
- либо \`epsilon (пустая строка)

Терминалы задаются строками в кавычках.
Нетерминалы задаются идентификаторами.

## 2. Лексическая структура

Входной текст разбивается на следующие токены:

- IDENT — идентификатор (нетерминал)
- STRING — строка в кавычках (терминал)
- `axiom — объявление аксиомы
- `is — начало правила
- `or — разделитель альтернатив
- `end — конец правила
- `epsilon — пустая альтернатива

## 3. Грамматика входного языка

Grammar   → Rules\
Rules     → Rule Rules | ε
Rule      → AxiomOpt IDENT \`is Alts \`end
AxiomOpt  → \`axiom | ε
Alts      → Alt AltsTail
AltsTail  → \`or Alt AltsTail | ε
Alt       → \`epsilon | Symbols
Symbols   → Symbol SymbolsTail
SymbolsTail → Symbol SymbolsTail | ε
Symbol    → IDENT | STRING
